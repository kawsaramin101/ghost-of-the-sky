- **Moon (Apollo lunar-module sites):** NASA NSSDCA / LRO frame (Mean Earth/Polar Axis): A11 0.674N 23.473E, A12 3.013S 23.422W, A14 3.646S 17.472W, A15 26.132N 3.633E, A16 8.973S 15.501E, A17 20.191N 30.772E.

- **Mars:** Opportunity = Eagle Crater 1.95S 354.47E (-5.53) per NASA/JPL (the rover later drove to Endeavour Crater / Perseverance Valley, shown as one marker at globe scale).
  Spirit 14.57S 175.48E (Arvidson et al.); Viking 1 22.48N 49.97W (NSSDC); Pathfinder ~19.13N 33.5W (sources differ by ~0.3 deg).
  Mars sources use different coordinate systems, so treat Mars positions as accurate to roughly +-0.5 deg. Fine for a globe marker, not for a map.
